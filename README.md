# CareBear Shop 🐻

A responsive e-commerce website for baby and toddler products, built with vanilla HTML, CSS, and JavaScript.

## Overview

CareBear Shop is a fully static front-end e-commerce experience designed for parents shopping for infants and toddlers. The site features a clean, warm aesthetic with a sidebar navigation, product browsing, a shopping cart, user sign-in, and an about page.

## Features

- **Home Page** — Hero banner, featured categories, and bestseller highlights
- **Bestsellers** — Curated grid of top-selling baby products with pricing
- **Stuffed Toys** — Dedicated department page for plush and stuffed animals
- **Shopping Cart** — Add-to-cart flow with item management and order summary
- **Sign In / Register** — User authentication UI with social login options
- **About Us** — Brand story and company values page
- **Responsive Design** — Mobile-friendly layout with hamburger sidebar navigation
- **Custom Favicon** — Bear-themed browser icon

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantics |
| CSS3 | Styling, animations, and responsive layout |
| JavaScript (ES6) | Cart logic and interactive UI (modal, sidebar) |

## Installation

No build step required — this is a static website.

```bash
# Clone the repository
git clone https://github.com/KandyKochar/carebear-shop.git

# Open in browser
open carebearhome.html
```

Or simply open `carebearhome.html` directly in any modern browser.
